Smart Canteen Web Application

About the Project

The Smart Canteen Web Application is a web-based system designed to simplify the canteen food ordering process. It allows users to register, explore food items, place orders and access different canteen services through an organised interface.

Technologies Used

- HTML – Structure of web pages
- CSS – Styling and layout
- JavaScript – Client-side functionality
- SQL – Database management
- Backend Technologies – Server-side functionality

Key Features

- User Registration and Login
- Food Menu Display
- Online Food Ordering
- Payment Page
- Contact Page
- Backend Integration
- Database Connectivity

Project Structure

- "backend/" – Backend application files
- "css/" – Stylesheets
- "database/" – Database-related files
- "js/" – JavaScript files
- "index.html" – Main webpage
- "menu.html" – Food menu page
- "order.html" – Order page
- "payment.html" – Payment page
- "register.html" – User registration page
- "contact.html" – Contact page

Project Objective

The main objective of this project is to provide a convenient and organised digital platform for managing canteen food ordering and improving the overall user experience.

Learning Outcomes

- Practical experience in frontend web development
- Understanding of backend development
- Working with databases and SQL
- Understanding user registration and authentication
- Integrating multiple components into a web application

Project Type

Academic Mini Project
